# Chill Guy 2.0 Website

🌐 Visit the live website: [https://chillguy.adonr.dev](https://chillguy.adonr.dev)

# Project Overview

Chill Guy 2.0 is a zero-tax cryptocurrency token built on Ethereum. This website provides a sleek, user-friendly platform for users to learn about the token, follow a step-by-step guide to purchase it via MetaMask and Uniswap, and explore transparent tokenomics.  

The design emphasizes simplicity, security, and community engagement, ensuring a seamless experience for both novice and experienced crypto users.

---

# Technologies Used

- **JavaScript** – Dynamic functionality and interactions.  
- **HTML** – Structured content for web pages.  
- **Tailwind CSS** – Utility-first styling for responsive, modern design.  
- **Vite** – Fast development server and build tool.  
- **Git & GitHub** – Version control and collaborative workflow.  

---

# Usage

1. Visit the website: [https://chillguy.adonr.dev](https://chillguy.adonr.dev)  
2. Follow the step-by-step guide to purchase `$CHILL2.0` token via MetaMask and Uniswap.  
3. Explore the tokenomics section for locked liquidity, total supply, and contract details.  
4. Connect with the community via provided social links.
